# Drawing Maker

A standalone, kid-friendly drawing app maker for parents.

Enter a child's name, pick a favorite color, choose a target size, and download a personalized HTML drawing app with pixel-style title text, color swatches, draw/erase tools, and a live preview.

## Features

- Child name input with a 16-character limit
- Favorite color picker with generated matching swatches
- iPad, phone, and browser output sizes
- Live draw/erase preview
- Downloadable standalone HTML output
- Embedded Pixelify Sans title font

## Try It Locally

Open `index.html` in a browser, or open `outputs/drawing-app-maker.html` directly.

No build step is required.
